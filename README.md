## 🌐 Instant Online Deployment Instructions

### Option A: Netlify Drop (30 Seconds, No CLI required)
1. Visit [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop the `ai-portfolio` folder directly onto the page.
3. Your site is instantly live with a free, public `.netlify.app` URL!

### Option B: GitHub Pages (Permanent & Professional)
1. Create a new GitHub repository named `portfolio`.
2. Push the files in this folder to the repository:
   ```bash
   git init
   git add .
   git commit -m "feat: AI Personal Portfolio for Task 1"
   git branch -M main
   git remote add origin https://github.com/<your-username>/portfolio.git
   git push -u origin main
   ```
3. Go to **Settings > Pages > Branch: `main` > Save**.
4. Your portfolio will be live at `https://<your-username>.github.io/portfolio/`.
